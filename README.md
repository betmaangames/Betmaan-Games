## Preview locally
Extract the ZIP and open `index.html` in a browser. For a local server, use VS Code Live Server.

## Deploy with GitHub + Netlify
1. Create a GitHub repository and upload all files/folders from this ZIP.
2. In Netlify, choose **Add new project → Import an existing project**.
3. Connect GitHub and choose your repository.
4. Build command: blank. Publish directory: `.`.
5. Deploy.

## Deploy with Vercel
1. Import the GitHub repository into Vercel.
2. Framework preset: **Other**.
3. Build command: blank. Output directory: `.`.
4. Deploy.
